# Portfolio Web — Christian Fernández

> Portfolio personal y profesional desarrollado con **Astro 5**, **Tailwind CSS 4** y **TypeScript**, optimizado para máximo rendimiento, accesibilidad (WCAG) e indexación en motores de búsqueda y modelos de lenguaje (LLMO).

## 🚀 Stack Tecnológico

- **Framework**: [Astro](https://astro.build/) (Static Site Generation - SSG)
- **Estilos**: [Tailwind CSS](https://tailwindcss.com/)
- **Tipografía**: Geist Sans & Geist Mono (@fontsource)
- **Calidad de Código**: ESLint + Astro Check + TypeScript estricto
- **SEO & Social**: JSON-LD Schema (Person & TechArticle), Open Graph (1200x630), Twitter Cards
- **LLM Readiness**: Soporte para `/llms.txt` y configuración para rastreadores de IA en `robots.txt`

## 🛠️ Comandos de Desarrollo

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo local
npm run dev

# Chequeo estricto de tipos de Astro y TypeScript
npm run check

# Verificación de linter
npm run lint

# Compilación estática de producción
npm run build

# Previsualizar la build de producción
npm run preview
```
